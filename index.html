    Sobre este Dashboard

    1. O Contexto (Obra Alpha)

    Simulação de um empreendimento de R$ 1.5M. O painel utiliza EVM (Earned Value Management) para cruzar avanço físico e financeiro.

    2. A Narrativa dos Dados (Cenário Padrão)

    No estudo principal, a obra sofreu atrasos iniciais (Q1) e recuperou o prazo no meio do ano, mas ao custo de estourar o orçamento na fase final (AC > PV).

    3. Estudos de Caso Disponíveis

    Este dashboard permite alternar entre três visões estratégicas (menu superior):

    • Estudo Realista (Padrão): O cenário base auditado, com problemas reais de gestão e recuperação custosa.
    • Estudo Otimizado: Simula uma execução de alta performance (CPI > 1.0), com economia de recursos e entrega antecipada.
    • Estudo Crítico: Simula um colapso operacional, com atrasos graves e estouro orçamentário desde o início.
